训练数据量 & 时效性 数据更新时间不同 新版本掌握更新知识

开发范式

工具

Cursor

  • 代码编辑器，具有 AI 辅助编程能力
  • 有自己的大模型，支持调用一些其他 AI 模型，支持通过 API 增加模型
  • 提供收费服务：https://cursor.com/cn/dashboard

Cursor 自己做的：

  • 整合包括自己在内的多个厂商的大模型，支持模型切换与路由
  • 为编程场景进行优化的前后端体验 + 工具链集成
  • 代码理解的索引系统
  • 自动 diff、执行、规划的编程 Agent

Cursor 的“智能”来自：

  • 70% 来自大模型（Composer、OpenAI、Claude、DeepSeek 等）
  • 30% 来自 Cursor 自己做的工程化能力（上下文管理 + diff + 工程代理）

VSCode + Coplit

  • Coplit 是微软推出的一整套 AI 服务（UI + 模型 + 插件 + 产品线）
  • VSCode 是代码编辑器，融合 Coplit 具有 AI 辅助编程能力
  • Coplit 没有自己的大模型，主要调用主流 AI 模型（不全），不支持通过 API 增加模型
  • Coplit 提供收费服务：https://github.com/github-copilot/pro

Trae CN

  • 代码编辑器，具有 AI 辅助编程能力

Cline

  • 编辑器插件，编码 Agent 工具，可运行在多种编辑器当中
  • 没有自己的大模型，支持丰富多种大模型，支持通过 API 增加模型
  • 提供收费服务：https://app.cline.bot/dashboard

@anthropic-ai/claude-code

  • Anthropic 官方发布的“代码助手工具链”，可运行在 CLI 或多种编辑器当中
  • Claude 模型专用
  • 提供收费服务：https://app.cline.bot/dashboard

MCP 协议

MCP 是让模型（Model）通过宿主（Host）访问外部服务器（MCP Server）中工具和资源的协议：

角色 英文名 职责 类比
模型宿主 Model Host / Client 托管或调用大语言模型（如 ChatGPT、Claude、DeepSeek 等），并负责与 MCP 服务器通信 「用户代理」或「宿主 App」
大模型（LLM） Model / Assistant 执行自然语言推理、调用 MCP 工具、利用资源生成回答 ChatGPT、Claude 等
服务器 MCP Server / Tool Server 通过 MCP 协议暴露工具（tools）、资源（resources）、上下文（contexts）等给模型使用 插件服务器、第三方 API 服务
角色 功能定位 是否运行模型 是否暴露工具 是否直接与用户交互
Model Host 调度者 / 管理员 ✅（调用模型） ❌ ✅
Model 智能体（LLM） ✅ ❌ ✅
MCP Server 工具/数据提供方 ❌ ✅ ❌

开发网站

  • v0.dev 的应用场景是你不需要懂编程以及任何 IDE，只需要做网页界面，那么发送一个设计稿、截图，能马上生成一个不错的网页出来，特别适合不会编程的产品经理、或者要做复杂的网页 UI（最佳搭配是 TailwindCSS 和 ShadcnUI），并且所见即所得。
  • bolt.new 适合你要做一个小网站，希望可视化编辑，做完一键部署发布，尤其适合前端不熟练网站简单的场景。
